# Scripts — Automation Utilities

Helper scripts for building and publishing the manuscript.

| Script | Purpose |
|--------|---------|
| `build_pdf.sh` | Build PDF from manuscript |
| `build_latex.sh` | Build LaTeX from manuscript |
| `validate.sh` | Project validation (alternative to tests/) |

## Usage

```bash
bash scripts/validate.sh
bash scripts/build_pdf.sh
bash scripts/build_latex.sh
```
