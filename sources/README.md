## Notes

- Only documents that are publicly redistributable should be stored here.
- Documents subject to ITAR or export-control restrictions must NOT be 
  included; instead, reference their public metadata only.
- File naming convention: `[Identifier]_[ShortTitle].pdf`
  - Example: `DSG-RQMT-001_Gateway_System_Requirements.pdf`

## Where to Find

Most NASA technical documents are available through:
- NASA Technical Reports Server (NTRS): https://ntrs.nasa.gov
- NASA Gateway Program public releases
- IEEE / AIAA conference proceedings (for technical papers)
